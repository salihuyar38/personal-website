# Personal Website

Salih Uyar's personal website and blog — plain HTML, CSS and JavaScript, no build step.

- `index.html` — home page (about, blog list, contact form)
- `blog/` — blog posts
- `css/style.css` — all styles
- `js/main.js` — navigation, scroll animations, contact form

The contact form sends messages through [FormSubmit](https://formsubmit.co).

Served with GitHub Pages from the `main` branch.
